# Steel City Integrators autonomous system v1.2

## Implemented

- Public Birmingham-focused website and transparent fee schedule
- Phone, live-text, remote and three-zone on-site prepaid services
- Stripe-hosted Checkout Sessions created server-side
- Server-side payment and amount verification before scheduling
- Single-use payment enforcement for appointment creation
- Google Calendar availability and event creation
- Customer confirmation plus internal paid-booking alert
- 24-hour and 2-hour appointment reminder engine
- Post-service follow-up engine
- CRM lead creation and appointment linkage
- Daily operations summary with payment and SMS readiness
- Privacy policy, booking terms, structured data, sitemap and robots file

## Account-dependent activation

- Stripe identity, payout and live-key authorization
- Existing Apps Script deployment update and one-time `upgradeSystemV12()` execution
- Google Voice identity verification for automated SMS
- Google Business Profile verification and publication

The website and automation code deliberately keep payment credentials out of the repository.
